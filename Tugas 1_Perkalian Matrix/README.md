# Tugas 1: Perkalian Matriks untuk Array 3 Dimensi

## Deskripsi
Tugas ini merupakan bagian dari mata kuliah Pengolahan Citra Digital (PCD). Tugas ini berfokus pada pembuatan program Python untuk menjalankan operasi perkalian matriks pada array 3 dimensi. Program dibuat dalam bentuk Command Line Interface (CLI), sehingga proses menjalankan program dan melihat hasilnya dilakukan melalui terminal.

## Tujuan
1. Memahami penerapan operasi perkalian matriks pada array 3 dimensi.
2. Mengimplementasikan operasi perkalian matriks menggunakan bahasa pemrograman Python.
3. Menjalankan program melalui Command Line Interface (CLI).
4. Menampilkan hasil pemrosesan matriks melalui terminal.

## Ketentuan Tugas
Membuat kode program yang dapat menjalankan perkalian matriks untuk array 3 dimensi menggunakan Python. Program harus dapat dijalankan melalui CLI Python.

## Teknologi yang Digunakan
- **Bahasa pemrograman:** Python
- **Antarmuka:** Command Line Interface (CLI)
- **Editor kode:** Visual Studio Code

## Struktur Folder
Folder tugas ini berisi file program Python dan file pendukung yang digunakan untuk menjalankan atau mengembangkan program perkalian matriks untuk array 3 dimensi.

## Cara Menjalankan Program

### 1. Buka Folder Tugas
Buka Visual Studio Code, lalu buka folder `Tugas 1_Perkalian Matrix` yang berisi file program Python.

### 2. Buka Terminal
Pada Visual Studio Code, pilih menu **Terminal → New Terminal** untuk membuka terminal.

### 3. Pastikan Lokasi Terminal
Pastikan terminal berada di dalam folder `Tugas 1_Perkalian Matrix`. Jika terminal masih berada di folder utama repository, jalankan perintah berikut:

```powershell
cd "Tugas 1_Perkalian Matrix"
```

### 4. Periksa File Program
Jalankan perintah berikut untuk melihat file yang tersedia:

```powershell
dir
```

Cari nama file Python yang digunakan untuk menjalankan program, dengan ekstensi `.py`.

### 5. Jalankan Program Python
Jalankan program menggunakan perintah berikut:

```powershell
python nama_file.py
```

Ganti `nama_file.py` dengan nama file Python yang sebenarnya. Sebagai contoh, jika nama file program adalah `T1_MatrixArray.py`, jalankan:

```powershell
python T1_MatrixArray.py
```

### 6. Amati Hasil Program
Setelah program dijalankan, perhatikan keluaran yang ditampilkan pada terminal. Hasil tersebut mengikuti implementasi kode perkalian matriks yang dibuat dalam program.

## Hasil yang Diharapkan
Program dapat dijalankan melalui terminal menggunakan Python dan melaksanakan operasi perkalian matriks untuk array 3 dimensi sesuai dengan kode yang diimplementasikan.

## Catatan
Pastikan Python sudah terpasang dan dapat dijalankan melalui terminal. Nama file pada perintah eksekusi harus disesuaikan dengan file program yang tersedia di dalam folder tugas ini.
